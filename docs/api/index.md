# Interface reference

The public interface is grouped by processing domain. Each page gives exact
parameters, return models, error behavior, and source links. Start with a
[workflow recipe](../recipes/index.md) if you do not yet know which function
fits your task.

- [Download](download.md): FDSN inventories, events, and waveforms
- [Inventory](inventory.md): station metadata analysis and manipulation
- [Waveforms](waveform.md): archival, conversion, coverage, merging, and SAC headers
- [Deconvolution](deconvolution.md): instrument-response removal
- [Decimate](decimate.md): phase-preserving file-batch decimation
- [Events](event.md): catalog preparation and event cutting
- [Corrections](correct.md): clock and component corrections
- [MCMC](mcmc.md): grid initialization and result collection

Use `help(object)` in Python for the same signatures and docstrings without
starting the documentation server.
